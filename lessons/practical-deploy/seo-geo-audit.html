배포하기

SEO/GEO 점검하기

SKILL을 활용해 SEO/GEO 점검을 맡기고 결과를 작업 목록으로 바꿉니다.

얻어갈 것

  • claude-seo skill을 설치하고 /seo audit을 직접 실행합니다.
  • audit 결과를 technical, content, schema, AI/GEO 같은 관점으로 나누고 개선 사항을 적용합니다.

SEO란

SEO(Search Engine Optimization)는 검색 엔진이 공개 페이지를 발견하고, 이해하고, 검색 결과에 보여줄 수 있게 정리하는 일입니다. 여기에 더해 GEO(Generative Engine Optimization)는 AI 검색과 AI 답변이 내 서비스를 읽고 인용할 수 있게 공개 근거를 정리하는 일입니다.

SEO에도 여러 층이 있습니다.

관점볼 것느좋카페 예시
기본 SEOtitle, description, URL, 제목 구조(heading), 본문 텍스트홈과 장소 상세가 어떤 서비스인지 바로 보이는가
Technical SEOrobots.txt, sitemap.xml, noindex, canonical URL, 렌더링크롤러가 공개 페이지를 찾고 읽을 수 있는가
콘텐츠/지역 정보 SEO지역명, 장소명, 추천 이유, 영업시간, 대상 사용자사용자가 찾는 장소 정보가 텍스트로 남아 있는가
GEOAI 검색과 AI 답변이 읽을 공개 근거AI가 느좋카페를 한 문장으로 설명할 수 있는가

SEO/GEO 점검하기

SEO/GEO audit은 새로운 기능을 만드는 일이 아닙니다. 이미 만든 서비스를 검색 엔진과 AI가 어떻게 읽는지 확인하는 일입니다.

이번에는 claude-seo를 설치해서 씁니다. Claude Code 안에서 /seo audit을 실행하면 검색 엔진과 AI 검색이 페이지를 어떻게 읽을지 여러 관점으로 점검해줍니다.

  • technical SEO: title, description, canonical, sitemap, robots, mobile, 성능
  • crawler 정책: Googlebot, AI search bot, user bot, training bot 허용/차단
  • structured data: Organization, LocalBusiness, BreadcrumbList 같은 schema 후보
  • content quality: 서비스 설명, FAQ, 인용 가능한 텍스트, 중복/빈약한 문장
  • reporting: 점수나 리포트보다 우선순위가 있는 작업 목록 만들기

먼저 skill을 설치합니다

P1claude-seo 설치하기
아래 Claude Code SEO skill의 README를 읽고 설치해줘.

설치하고 사용 방법도 간단하게 알려줘
P2/seo audit 실행하기
/seo audit [적용한 도메인 혹은 Vercel URL]

마무리

  • audit 결과는 점수가 아니라 technical, content, schema, AI/GEO 관점의 우선순위 작업 목록으로 바꿔서 하나씩 적용합니다.
  • 개선을 적용했으면 다시 배포하고, /seo audit을 한 번 더 돌려 바뀐 결과를 확인합니다.
