배포하기

링크 미리보기 설정하기

링크를 공유했을 때 보이는 장면(브라우저 탭·공유 카드·첫 화면·실패 화면)을 점검합니다.

링크를 보냈을 때 볼 장면

  • 브라우저 탭: favicon, title, 서비스 이름
  • 공유 카드: OG title, description, image
  • 첫 진입 화면: 홈, 지도, 장소 상세, 로그인 필요 화면
  • 실패 화면: 존재하지 않는 URL, 예기치 못한 에러

Checklist

  • 브라우저 탭 title과 favicon이 서비스 이름으로 보이는지 확인합니다.
  • 페이지 description이 공유 카드에서 어색하지 않은지 봅니다.
  • OG title, description, image가 production URL 기준으로 나오는지 확인합니다.
  • 카카오톡, 슬랙, 디스코드 같은 공유 미리보기에서 제목·설명·이미지가 나오는지 봅니다.
  • 존재하지 않는 URL과 예상치 못한 에러 화면이 빈 페이지로 끝나지 않는지 확인합니다.

프롬프트 (복사할 수 있게)

P1링크 미리보기 점검
느좋카페를 첫 사용자에게 공유하기 전에 링크를 열기 전후의 장면을 점검해줘.

- favicon
- title과 description
- OG title, description, image
- canonical URL과 production site URL
- 카카오톡, 슬랙, 디스코드 공유 미리보기
- 404/에러 화면
