AI 티 덜기

stageshow로 진짜 제품 같은 데모 UI 만들기

X 디자인 총괄 벤지 테일러의 stageshow 스킬로 AI 티 없는 제품 데모 UI를 만드는 방법

얻어갈 것

  • AI가 만든 화면에서 나는 "AI 티"가 무엇인지 체크리스트로 확인합니다.
  • stageshow 스킬을 설치하고, 마케팅 페이지에 쓸 제품 데모 UI를 만들어봅니다.

"AI 티"는 어디서 나나

AI에게 화면이나 데모를 만들어 달라고 하면, 동작은 해도 어딘가 "생성된 티"가 나는 결과가 자주 나옵니다. stageshow는 가짜 UI가 실패하는 방식을 다섯 가지로 정리합니다.

실패 방식증상
너무 많음디테일이 과해서 오히려 생성된 것처럼 보입니다.
와이어프레임너무 단순하거나 작게 만들어 성의 없어 보입니다.
박스형전체 창을 통째로 축소해 스크린샷처럼 보입니다.
평탄함모든 요소가 같은 시각적 무게라 눈 둘 곳이 없습니다.
심심함회색 창에 커서만 움직이는, 의미 없는 장면입니다.

스파클·보라색 그라데이션 같은 "AI 스타일 로고", 균일한 회색 막대, 원인 없는 움직임과 갑작스러운 리셋도 전형적인 AI 티로 꼽습니다.

stageshow란

stageshow는 X(구 트위터) 디자인 총괄 벤지 테일러(Benji Taylor)가 공개한 스킬로, 가짜 제품 UI를 실제 제품처럼 보이게 만드는 도구입니다. 랜딩 페이지의 히어로·피처 카드 일러스트, 커서가 움직이며 제품을 시연하는 데모 애니메이션을 만들 때 씁니다.

  • 핵심 철학은 "저자가 만든 일러스트레이션이지, 브라우저 자동화가 아니다"입니다. 실제 화면을 녹화하는 게 아니라, 보여줄 것만 남긴 장면을 코드로 그립니다.
  • 실제 제품처럼 읽히되 시청자에게 필요한 것만 남기고, 의도적으로 프레이밍하고, 모든 움직임에 목적이 있어야 한다는 원칙을 따릅니다.
  • React 기반 키트가 함께 옵니다: Window·Phone 같은 프레임, Bar·Text·Row·Avatar·Chart 같은 부품, 그리고 커서의 move·click·type을 연출하는 Act API.

어떻게 사용하나

스킬을 설치하면 Claude가 아래 7단계 워크플로우를 따라 작업합니다. 사용자는 만들고 싶은 장면만 설명하면 됩니다.

  1. 매체와 크기: 정지 이미지인지 애니메이션인지, 어디에 들어가는지 정합니다 (히어로 카드는 약 720×340px).
  2. 룩 맞추기: 내 제품의 색·폰트를 키트 토큰에 매핑하고 light / dark / blueprint / glass 테마를 고릅니다.
  3. 스토리: 10~16초 안에 3~5개 장면과 하나의 페이오프(결정적 순간)로 구성합니다.
  4. 예제에서 시작: 48개 골드 예제 중 가장 가까운 것을 복사해 구조를 유지한 채 바꿉니다.
  5. 화면 구성: 실제 텍스트는 3~7개만 쓰고 나머지는 추상 부품으로 채웁니다.
  6. 안무: Act API로 커서 이동·클릭·타이핑을 연출합니다. 모든 움직임에 원인이 있어야 합니다.
  7. 리허설: 멈춰 있어도 이야기가 전달되는 포스터 프레임부터 점검하고, 프레임 검증을 돌립니다.

사용은 평소처럼 자연어로 부탁하면 됩니다. 느좋카페라면 이렇게 쓸 수 있습니다.

P2느좋카페 데모 일러스트 만들기
stageshow 스킬로 느좋카페 랜딩 페이지 히어로에 넣을 데모 일러스트를 만들어줘.

- 지도에서 카페 핀을 클릭하면 상세 카드가 열리고 북마크를 누르는 10초짜리 애니메이션
- 히어로 카드 크기(약 720x340), 우리 서비스 색을 반영한 light 테마
- 실제 서비스처럼 보이게 하고, 과한 장식이나 의미 없는 움직임은 빼줘

stageshow가 만드는 건 마케팅·소개용 "일러스트"입니다. 실제 기능 검증은 검증 고도화하기에서 다룬 Playwright CLI 같은 도구로 실제 화면을 돌려서 합니다. 둘을 혼동하지 않습니다.

유형별 예시 프롬프트 모음

다른 프로젝트에서도 바로 쓸 수 있도록 기능 유형별로 정리한 예시입니다. 유형마다 서로 다른 가상 앱을 예시로 넣었습니다.

1. AI 채팅 데모

/stageshow AI 냉장고 셰프 채팅 데모. 냉장고 사진을 올리면 "계란, 대파, 김치 발견" 태그가 붙고, 레시피 카드 3장이 펼쳐진 뒤 하나를 누르면 단계별 타이머가 시작되는 흐름.
/stageshow AI 법률 상담 채팅. 월세 계약서를 올리면 "위험 조항 2개"가 빨간 하이라이트로 표시되고, 수정 문구를 제안하는 카드가 뜨는 데모.
/stageshow AI 운동 코치 채팅. "무릎이 안 좋아요, 30분만" 입력 → 생각 중 → 주간 루틴 카드가 열리고, 운동 하나를 눌러 캘린더에 추가하는 흐름.
/stageshow AI 옷장 스타일리스트. "내일 비 오고 면접 있어" 입력 → 날씨 칩이 먼저 뜨고 → 내 옷장 사진들로 코디 3벌을 제안하는 카드.

2. 랜딩 페이지 히어로

/stageshow 탄소 발자국 트래커 앱 히어로. 지도 위로 오늘 이동 경로가 그려지고, 오른쪽 카드의 "오늘 배출량"이 롤링되며 나무 아이콘이 하나 자라는 장면. 가로 1000px.
/stageshow 실시간 통역 이어폰 앱 히어로. 폰 화면에 두 언어 말풍선이 동시에 스트리밍되고, 다이내믹 아일랜드에 "🇯🇵 → 🇰🇷 통역 중" 파형이 움직이는 장면.
/stageshow 중고거래 AI 가격 감정 앱 히어로. 카메라로 스니커즈를 찍으면 스캔 라인이 지나가고, "적정가 128,000원" 카드와 시세 그래프가 튀어나오는 정지 이미지.
/stageshow 반려식물 케어 앱 다크 히어로. 화분 센서 대시보드에서 수분 수치가 떨어지면 폰 잠금화면에 "몬스테라가 목말라요 💧" 알림이 뜨는 장면.

3. 기능 소개 그리드(벤토)

/stageshow 1인 창업자용 올인원 앱 벤토 그리드. 타일 5개: 매출 차트(큰 히어로 타일), AI 고객 응대 채팅, 인보이스 자동 발송, 오늘의 할 일, 은행 연동 잔액.
/stageshow 수면 관리 앱 다크 벤토. 수면 단계 그래프, 코골이 녹음 파형, 아침 기상 알람 폰 화면, "평균 7시간 12분" 큰 숫자 타일.
/stageshow 여행 공동 정산 앱 컬러풀 벤토. 친구 아바타들이 연결된 정산 다이어그램, 영수증 스캔 타일, 환율 자동 변환, "민지가 32,000원 보냈어요" 알림 타일.
/stageshow 개발자 모니터링 툴 룰드(줄 그어진) 다크 벤토. 에러 그래프 급증, 터미널 로그, 배포 타임라인, Slack 알림 타일.

4. 핵심 인터랙션 하나 클로즈업

/stageshow 가계부 앱에서 카드 결제 내역 하나를 "커피" 카테고리로 드래그하면 월 예산 바가 차오르고 "예산 80% 사용" 경고가 뜨는 클로즈업.
/stageshow 협업 문서에서 문장을 드래그로 선택하자 AI 메뉴가 뜨고 "더 짧게"를 누르면 문장이 줄어드는 1.4배 확대 데모.
/stageshow 구독 관리 앱에서 넷플릭스 같은 구독 행을 스와이프해 해지하면 아래 행들이 올라오고 "월 17,000원 절약" 배지가 뜨는 폰 화면.

5. 시스템 흐름(커서 없이 자동 진행)

/stageshow 스마트 택배함 흐름. 기사 앱에서 "보관 완료" → 택배함 칸에 불이 켜지고 → 내 폰에 QR 알림이 오는 3단계 시스템 스토리.
/stageshow 병원 예약 자동화 흐름. 환자 카톡 예약 요청 → 캘린더에 빈자리가 채워지고 → 전날 리마인더 알림이 발송되는 애니메이션.

6. 실시간 협업·멀티 디바이스

/stageshow 팀 화이트보드 앱에서 이름 달린 커서 3개가 동시에 포스트잇을 붙이고, 같은 주제끼리 자동으로 묶이며 그룹 제목이 생기는 데모.
/stageshow 노트북 웹에서 사진을 편집하면 옆 아이패드와 폰 화면에도 실시간으로 반영되는 멀티 디바이스 구도.

쓰는 순서 팁: 먼저 랜딩 페이지 맨 위에 넣을 히어로를 정하고, 그 아래에 벤토 그리드로 기능을 훑은 뒤, 기능별로 클로즈업이나 채팅 데모를 하나씩 넣으면 랜딩 페이지 한 장이 완성됩니다.

마무리

  • AI 티는 디테일 과잉, 균일한 회색 박스, 원인 없는 움직임처럼 패턴이 정해져 있어서, 체크리스트로 걸러낼 수 있습니다.
  • stageshow는 "보여줄 것만 남긴 장면을 코드로 그린다"는 원칙으로, 랜딩 페이지에 쓸 데모 UI를 실제 제품처럼 만들어줍니다.
