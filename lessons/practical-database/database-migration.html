chapter 05lesson 5.3privateworkbench

지도 데이터베이스 구축하기

places 테이블 마이그레이션하기

places 테이블을 만들고 cafes.json 데이터를 Supabase로 옮깁니다.

얻어갈 것

  • 마이그레이션이 데이터베이스 구조를 실제로 바꾸는 작업이라는 걸 이해합니다.
  • places 테이블을 만들고 기존 데이터를 넣은 후 서비스에 반영합니다.

마이그레이션이란

  • 마이그레이션은 데이터베이스 구조를 바꾸는 작업입니다.

  • 새 테이블을 만들거나, column을 추가하거나, 제약 조건을 바꾸는 일을 실제 데이터베이스에 반영할 때 씁니다.

  • 이번 마이그레이션은 places 테이블을 만들고 기존 데이터를 INSERT 하는 작업입니다.

이번 작업 범위

단계할 일확인할 것
1places 테이블 만들기column, type, nullable(비워 둘 수 있음)
2cafes.json 데이터 넣기row 개수, 샘플 데이터
3서비스 코드 전환로컬 JSON 대신 Supabase 조회
4화면 검증지도와 카드가 그대로 보이는지

Migration 준비하기

P1마이그레이션 준비
Supabase에서 places 테이블과 데이터 추가 마이그레이션을 준비해 줘.

확인할 것 
1. 기존에 생성한 places 스키마 생성 로직
2. data/cafes.json 데이터 추가 로직

서비스 코드 전환하기

  • 여기서부터는 데이터베이스 작업이 아니라 서비스 코드 변경입니다.
  • 기존 cafes.json을 읽던 부분을 찾고, 같은 장소 데이터를 Supabase places 테이블에서 읽도록 바꿉니다.
  • 화면은 그대로 유지하고, 데이터의 출처만 로컬 파일에서 Supabase로 바꿉니다.
P3서비스 데이터 소스 전환하기
기존 cafes.json을 읽던 방식을 Supabase places 테이블에서 읽는 방식으로 바꿔줘.

변경 후 지도와 카드가 기존처럼 동작하는지도 확인해줘.

마무리

  • 데이터베이스 마이그레이션을 마친 후 서비스 로직도 supabase를 활용하도록 변경하였습니다.
