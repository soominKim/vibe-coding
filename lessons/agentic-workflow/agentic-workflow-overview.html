에이전틱 워크플로우

에이전틱 워크플로우란

AI에게 일을 맡길 때 계획, 구현, 검증, 학습을 하나의 루프로 보는 관점

얻어갈 것

  • 큰 기능을 "한 번에 만들어줘"가 아니라 탐색/계획 -> 구현 -> 검증 -> 학습으로 나눠 맡기는 이유를 확인합니다.
  • 에이전틱 워크플로우를 위한 스킬을 다운받습니다.

왜 여기서 흐름을 바꾸나

지금까지는 데이터 읽기, Git, 데이터베이스, 디자인, 로그인처럼 주요 구성요소를 하나씩 다뤘습니다. 앞으로 서비스를 더 개발하다 보면 코드는 복잡해지고, 한 번에 원하는 결과가 나오지 않을 수 있습니다.

  • 로그인 이후의 기능은 화면, 데이터, 권한, 예외 상태가 함께 움직입니다.
  • "지도에 리뷰 추가해줘"처럼 한 줄로 맡기면 AI가 어디까지 만들고 어디서 멈춰야 하는지 알기 어렵습니다.
  • 구현이 맞아 보여도 DB row, RLS, 새로고침 뒤 상태, 모바일 화면, 에러 같은 것을 검증해야 합니다.
  • 그래서 하나의 기능을 개발한다는 것은 계획, 구현, 검증, 학습까지 이어지는 단위가 되어야 합니다.
방식빠른 점막히는 지점
그냥 해줘작은 UI 수정, 문구 변경에는 빠릅니다.범위와 완료 조건이 흐려집니다.
대화로 계속 수정눈에 보이는 결과를 빨리 맞출 수 있습니다.같은 설명을 반복하고, 코드 품질은 뒤늦게 발견합니다.
에이전틱 워크플로우시작 전에 기준을 잡고 실행합니다.처음에 범위와 검증 방식을 쓰는 시간이 필요합니다.

에이전틱 워크플로우

에이전틱 워크플로우는 AI에게 한 번에 결과물을 요구하는 방식이 아니라, 작업을 단계로 나누고 실행하는 방식입니다.

단계AI에게 맡길 일사람이 볼 것
탐색/계획(Plan)코드베이스를 읽고, 모호한 요구사항을 질문하고, 설계안과 실행 계획으로 정리합니다.이번에 만들 것과 만들지 않을 것.
구현(Implementation)계획의 완료 조건을 체크리스트로 바꾸고 코드를 수정합니다.계획대로 잘 구현되었는지.
검증(Verification)테스트, 빌드, 브라우저 시나리오, diff 리뷰로 증거를 모읍니다.AI의 완료 선언이 아니라 실제 증거.
학습(Compounding)반복된 실수, 검증 명령, 프로젝트 규칙을 남깁니다.다음에도 남길 만큼 반복 가능한 내용인지.

검증과 코드리뷰를 통과한 뒤에야 풀 리퀘스트(PR), 배포, 다음 작업으로 넘깁니다.

Skill로 책임을 나눕니다

이 수업에서는 이 워크플로우를 Skill 묶음으로 제공하는 Superpowers를 씁니다.

Superpowers란

Superpowers는 Claude Code 같은 AI 코딩 에이전트가 생각 없이 바로 코드를 작성하지 않고, 요구사항을 탐색·설계한 뒤 계획 → 구현 → 테스트 → 코드 리뷰 → PR/마무리 순서로 일하도록 도와주는 오픈소스 개발 방법론 및 Skill 모음입니다. 각 기능은 독립된 SKILL.md 파일로 정의되며, 적절한 상황에서 Claude가 자동으로 사용하거나 사용자가 슬래시 명령어로 직접 실행할 수 있습니다.

  • 탐색: brainstorming으로 아이디어·요구사항을 질문하며 정리
  • 계획: writing-plans로 실행 가능한 세부 작업 계획 생성
  • 구현: executing-plans 또는 subagent-driven-development로 단계별 코딩
  • 검증: TDD, 디버깅, 완료 검증, 코드 리뷰를 결합
  • 마무리: 테스트 결과 확인 후 PR·병합 등 선택

Skill들 추가하기

수업에서는 설치 명령을 외우기보다, 에이전트에게 README를 읽고 설치하게 시킵니다.

P1Superpowers Skill 설치하기
https://github.com/obra/superpowers README를 읽고, Claude Code에 Superpowers 관련 Skill들을 모두 설치해줘.

- README의 Claude Code 공식 마켓플레이스 설치 명령을 기준으로 진행해줘.
- 현재 프로젝트뿐 아니라 모든 프로젝트에서 사용할 수 있도록 user scope로 설치해줘.
- 설치 후 활성화 상태와 설치된 Skill 목록을 확인해줘.
- /superpowers:brainstorming 같은 슬래시 명령어를 사용할 수 있는지 확인해줘.
- 설치 결과와 필요한 후속 조치를 간단히 요약해줘.

직접 설치하려면 Claude Code 입력창에서 /plugin install superpowers@claude-plugins-official을 실행해도 됩니다. 설치가 끝나면 새 세션을 열고, / 자동완성 목록에 /superpowers:brainstorming이 보이는지 확인합니다.

이번 챕터에서 다룰 것

  • 계획하고 맡기고 검증하기: 설계안과 실행 계획을 작업 주문서와 채점표로 보고, 구현과 검증까지 한 번에 묶습니다.
  • 에이전트에게 검증 최대한 위임하기: 사람이 눈으로 하고 직접 테스트하는 흐름을 에이전트에게 최대한 위임합니다.
  • 긴 작업 돌려보기: 여러 사용자 흐름이 섞인 작업을 하나의 계획 안에 담아서 구현해보기.
  • 배운 걸 프로젝트에 남기기: 반복된 실수, 검증 명령, Skill 후보를 프로젝트 규칙으로 바꿉니다.

마무리

  • 바이브코딩은 즉흥적인 요청으로 시작할 수 있지만, 기능이 커지면 에이전틱 워크플로우가 필요합니다.
  • 다음 레슨부터는 계획, 구현 그리고 검증에 대해 더 자세하게 알아보도록 하겠습니다.
